# 瑞士杠杆擒纵 · 三维教学教具

面向钟表学校课堂的三维瑞士杠杆擒纵（Swiss lever escapement）教学系统。
擒纵轮、擒纵叉、叉瓦、冲击钉、摆轮游丝按**真实几何尺寸与接触关系**运动；
所有锁接、释放、传冲、落下事件由**线段/圆接触几何求根**算出，而非播放预录动画。

## 运行

```bash
npm install
npm run dev      # 本地开发（WebGPU，Chrome/Edge 113+）
npm run build    # 类型检查 + 生产构建
npm test         # 验收测试（18 项，含教材数据与能量守恒）
npm run tune     # 参数敏感度/标定脚本（Node 端，无需浏览器）
```

无 WebGPU 环境时页面显示回退提示，但全部接触计算与指标仍由 TypeScript
引擎在 Node/浏览器主线程完成（`src/core/dynamics.ts` 是 WGSL 求解器的同算法镜像）。

## 四个教学页面

| 页面 | 内容 |
| --- | --- |
| 擒纵演示 | 整机运转 + 实时指标卡（锁深/落下/提升角/压力角）+ 四阶段事件流 + 能量核算 + 卡滞诊断 |
| 分阶段慢放 | 一拍拆成锁接/释放/传冲/落下，逐帧拖动，接触面高亮、受力方向叠加，0.05–1× 变速 |
| 零件拆解 | 爆炸滑块分离各零件，z 向剖切观察叉瓦与轮齿厚度方向啮合，附真实尺寸清单 |
| 参数调节 | 改叉瓦角度/瓦尖半径/轮齿齿形，指标即时重算；锁深≤0 自动判定打滑跳齿并定位卡滞 |

## 架构（单事实源）

```
src/core
  math2d.ts      2D 向量、线段相交/最近点、SAT、求根（TS 与 WGSL 共用同一约定）
  types.ts       参数、状态、命名面标签、分析结果类型
  defaults.ts    教材比例默认参数 + 三种自编齿形预设
  geometry.ts    参数化生成轮齿/叉瓦/叉口/冲击钉/摆轮游丝，边带语义标签
  kinematics.ts  位姿变换、线段-线段/圆-线段有符号间隙
  tracker.ts     连续接触跟踪（最小间隙优化，处理近平行传冲面的单点相切）
  escapement.ts  一拍事件引擎：四阶段求根 -> 锁深/落下/提升角/跳齿/卡滞
  energy.ts      能量守恒：轮力矩做功 vs 游丝吸能，含库仑摩擦耗散
  dynamics.ts    速度级顺序冲量求解器（WGSL compute 的 TS 镜像，含摩擦）
src/gpu
  mesh.ts        2D 轮廓挤出三角棱柱，面语义 id
  shaders.ts     WGSL compute（接触约束求解）+ render（着色/高亮/剖切）
  mat4.ts        列主序矩阵、轨道相机
  renderer.ts    WebGPU 设备/缓冲/管线管理，contact 上传与 dispatch
  scene.ts       几何 -> 渲染对象装配、爆炸方向
src/ui           集中式 store、四页面、画布视图、轨道相机与受力叠加
```

### 接触为什么是"算"出来的

- 每个零件的每条边带语义标签（`wheel-lock`/`wheel-impulse`/`stone-lock`/`stone-impulse`/叉口壁）。
- 事件引擎在每个阶段指定一个主动角，用 `tracker.projectContact` 在局部窗口
  最小化命名面之间的有符号间隙，解出其余刚体角度，解支随主动角连续不外推。
- 锁接深度 = 齿尖沿瓦锁面越入瓦尖的弧长 / 接触半径；
  落下角由齿距周期约束（半拍净前进 = 360/齿数/2）与传冲末位置反推；
  提升角取传冲中叉角位移，摆轮升角经冲击钉-叉口杠杆比折算。

## 验收数据（`npm test`，club 齿形默认参数）

| 指标 | 计算值 | 教材标准 | 结论 |
| --- | --- | --- | --- |
| 锁接深度 | 1.24° | 1.0–1.5° | ✓（≤0.2° 公差） |
| 落下角 | 1.57° | 1.0–2.0° | ✓ |
| 摆轮提升角 | 8.51° | 8–10° | ✓ |
| 一拍轮转角 | 12.000° | 360/15/2 = 12° | ✓ 严格相等 |
| 能量偏差 | 0.017% | 轮做功 = 游丝吸能 | ✓ |

- 一轮齿（24°）对应摆轮一个完整往复（两个半拍，各 12°）。
- 三种自编齿形：`club`（标准钩爪齿）、`steepClub`（陡钩爪，浅锁深）、
  `ratchet`（棘齿，锁深 -0.10°，稳定触发打滑跳齿并报告卡在出瓦接齿阶段）。
- 能量：无摩擦时 `τ·Δθ_wheel = ½k·θ_lift²`；有摩擦时游丝吸能 = 轮做功 − μN·滑动路径。

## 关键标定参数

默认游丝刚度 `springStiffness=8.08` 由能量守恒反解
（`k = τ·Δθ / (½θ²)`），使摆轮每拍获得能量恰好等于传冲阶段叉瓦对轮做的功。
`stoneReach=2.81`、轮齿 `impulseFaceBiasDeg=-30`（传冲面平行度 >0.99）
经 `npm run tune` 扫描标定到教材指标。
